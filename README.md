# 🎉 메가파이트 - OK캐쉬백 공구 투표 게임

**"당신이 응원하는 메가 파르페가 다음 공구의 주인공이 된다!"**

---

## 📋 프로토타입 개요

- **목적**: OK캐쉬백 쇼핑탭의 바이럴 게임 프로토타입 (신규유저 유입 + 공구 선호도 파악)
- **기간**: 1분 데모 라운드 (운영 시 4시간)
- **컨셉**: 메가MGC커피의 두 시즈널 파르페를 두고 벌이는 실시간 응원 배틀
- **핵심 메커니즘**:
  - 팀 선택 → 투표 후 결과 노출
  - 연타(게이지/쿨다운) → 실시간 점수 누적
  - 1분 후 우승팀 결정 → 다음 공구 확정
  - 기여도 기반 보상 (컨셉)

## 🎨 각 파일 역할 & 수정 포인트

### `config.js` — 게임 설정 (가장 자주 수정)
```javascript
const GAME_CONFIG = {
  title: "메가파이트",                    // 게임 제목 변경
  roundSeconds: 60,                      // 라운드 길이 (운영 시 14400)
  teams: {
    A: { product: "...", color: "#..." }, // 상품명/색상 변경
    B: { ... }
  },
  benefits: [ ... ],                     // 참가 혜택
  // ... 기타 설정
};
```

**스왑 예시:**
- 다른 제휴처/상품으로 바꾸기 → `config.js`의 `teams.A`, `teams.B` 수정
- 라운드 길이 4시간으로 → `roundSeconds: 14400`
- 혜택 변경 → `benefits` 배열 수정

### `mock.js` — 가짜 데이터 엔진
⚠️ **서버 연동 시 이 파일 전체 삭제 예정**

현재:
- `recordTap()` → 연타 기록 + 점수 증가
- `startRealtimeSimulation()` → 상대팀이 계속 연타하는 시뮬레이션
- `getGameState()` → 게임 상태 조회

서버 연동 시:
```javascript
// mock.js 대신 실제 API 호출
const response = await fetch('/api/game/tap', { method: 'POST' });
const state = await response.json();
```

### `app.js` — 게임 로직
- 화면 전환 (인트로 → 배틀 → 결과)
- 이벤트 리스닝 (탭, 팀 선택, 공유)
- UI 업데이트 루프
- 음향/햅틱 피드백

### `style.css` — 스타일
- 삼김파이트 레이아웃 + 40대 여성 톤
- 반응형 설계 (모바일 우선)
- 애니메이션 (슬라이드, 바운스, 떠오르는 숫자)

## 📊 게임 플로우

1. **인트로 (팀 선택)**
   - 메가 2개 파르페 카드 노출
   - 탭: "메인" / "참가 혜택" / "우승 상금"
   - 응원하기 버튼 클릭 → 배틀 진입

2. **배틀 (1분 진행)**
   - 실시간 VS 막대 (양팀 점수, 비율)
   - 타이머 카운트다운
   - 큰 탭 버튼으로 연타 → 내 팀 점수 증가
   - 상대팀도 자동으로 점수 증가 (mock)
   - 게이지/쿨다운: 연타 4회 후 0.5초 쿨다운

3. **결과**
   - 우승팀 공표
   - 내 연타 횟수 / 상금 표시
   - 공유하기 버튼 (바이럴 엔진)
   - "다음 라운드" 버튼 클릭 → 리셋

## 🎯 바이럴 메커니즘 (설계 기반)

| 요소 | 역할 | 효과 |
|---|---|---|
| **편 가르기 투표** | 의견/정체성 표현 | 참여 욕구 자극 |
| **실시간 VS 막대** | 경쟁 긴장감 | "내 편 지고 있어" → 공유 동기 |
| **연타 게이지** | 참여 깊이 확보 | 체류 시간 ↑, 습관성 ↑ |
| **기여도 시각화** | "내가 이겼다" 감각 | 오너십 강화 → 공유 텍스트 개인화 |
| **친구 초대 암묵** | 협력 구조 | "5천명 넘으면 가격 인하" 같은 집단 목표 |
